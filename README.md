# Lottes Project

A household chores app — recurring task scheduling, assignment across household
members, and timed reminders.

**Status:** scaffold only. No product features yet; the spec is still being written.

## Setup

```bash
pnpm install
pnpm dev
```

`pnpm dev` runs the Vite client and the Worker together on one origin, so
`fetch('/api/...')` works with no CORS and no proxy config.

## Commands

| Command | What it does |
| --- | --- |
| `pnpm dev` | Client + Worker dev server |
| `pnpm verify` | typecheck + lint + test — run before committing |
| `pnpm test` | Vitest, once |
| `pnpm test:watch` | Vitest, watching |
| `pnpm check` | Biome format + lint, autofixing |
| `pnpm build` | Production build |
| `pnpm deploy` | Build and push to Cloudflare |

## Layout

```
src/client/   React app (browser only)
src/worker/   Hono API (Workers runtime only)
src/shared/   Pure domain logic, used by both
```

Client and worker must not import from each other; anything common belongs in
`src/shared`. Each directory has its own tsconfig enforcing the right runtime types.

`worker-configuration.d.ts` is generated by `wrangler types` (run automatically on
`pnpm install`) and is not committed.

See [CLAUDE.md](CLAUDE.md) for conventions.
